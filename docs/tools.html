11 — ОПЫТ
Привычки, которые спасают

Не технологии, а дисциплина — именно она отличает спокойное окно работ от ночного инцидента.

Бэкап до изменения
Перед любой правкой — show running-config в файл или copy run tftp:. Без исходного состояния откат превращается в угадывание.
Страховка от потери доступа
Меняете ACL, маршрутизацию или интерфейс управления удалённо — сначала reload in 10. Всё прошло хорошо — reload cancel. Связь пропала — через 10 минут устройство вернётся к сохранённому конфигу.
Одно изменение за раз
Поменяли три вещи и всё сломалось — непонятно, какая виновата. Меняйте по одной, проверяйте после каждой.
Обратный путь
Ping не проходит — проверьте не только маршрут туда, но и маршрут обратно. Половина «загадочных» проблем — асимметрия или отсутствующий обратный маршрут.
«Что менялось?»
Первый вопрос при любом инциденте. Работало вчера, не работает сегодня — ищите изменение: конфиг, прошивка, кабель, сосед, сертификат, время.
Документируйте сразу
description на каждом интерфейсе, актуальная схема и таблица адресов. Через полгода вы сами не вспомните, куда ведёт Gi0/17.

MPLS: коммутация по меткам вместо разбора IP на каждом хопе

На входе в MPLS-домен пакету присваивается метка. Дальше внутри домена коммутация идёт по метке (swap), а не по IP-адресу — быстрее и это основа для сервисов вроде VPN поверх общей инфраструктуры.

ИСТОЧНИКlinkmeup / СДСМ, гл. 10
ФОРМАТтеория + схема + квиз
ВРЕМЯ~10 минут
Push → Swap → Pop на пути пакета
ключевой узел на схемесоседний / промежуточный узел
  1. 1Пакет без метки приходит на PE
  2. 2PE делает push: метка 100 добавлена
  3. 3P-роутер делает swap: метка 100 → 200
  4. 4PE-out делает pop, дальше — обычная IP-пересылка

P-роутеры (ядро) работают только с метками — им не нужно ни разу заглядывать внутрь IP-заголовка клиента.

01 — ТЕОРИЯ
Из чего состоит решение MPLS

Шесть понятий — фундамент перед L3VPN и L2VPN.

Проще говоря: пакету один раз на входе в сеть присваивают короткую метку, и дальше роутеры пересылают его по метке, не разбирая IP-заголовок на каждом хопе.

Зачем нужен MPLS
Метка позволяет коммутировать пакет по короткому фиксированному значению вместо разбора полного IP-заголовка на каждом узле, и служит основой для VPN-сервисов поверх общей инфраструктуры.
Label Stack
Пакет может нести несколько меток одновременно (стек): внешняя метка — транспортная (до PE), внутренняя — сервисная (VPN/VC).
Push / Swap / Pop
Три базовые операции с меткой: push — добавить метку на входе, swap — заменить метку транзитом, pop — снять метку перед выходом.
LDP
Label Distribution Protocol — протокол, которым соседние MPLS-роутеры автоматически договариваются, какая метка соответствует какому FEC.
PHP
Penultimate Hop Popping — предпоследний узел снимает метку заранее, чтобы последний узел (PE) не делал двойную работу.
FEC
Forwarding Equivalence Class — группа пакетов, обрабатываемых одинаково (например, идущих по одному LSP) — именно FEC привязывается к метке.
— ЧАСТЫЕ ЗАБЛУЖДЕНИЯ
Что обычно путают

Типичные неверные представления про эту тему — и как на самом деле.

КажетсяMPLS — это способ шифрования или туннелирования, как VPN.
На делеMPLS — это метод пересылки по меткам вместо разбора IP на каждом хопе; изоляция клиентов — лишь одно из применений поверх MPLS, а не суть самой технологии.
КажетсяМетка MPLS остаётся неизменной от начала до конца пути.
На делеНа каждом хопе метка заменяется (label swap) на новую, известную только соседнему роутеру — end-to-end метка не сохраняется.
02 — ПРОЦЕСС
Что происходит с меткой на каждом узле

Четыре шага — от входа в домен до выхода из него.

  • 1Вход — пакет без метки приходит на входной PE-роутер (ingress).
  • 2Push — PE добавляет метку, соответствующую нужному FEC/LSP.
  • 3Swap — каждый транзитный P-роутер меняет метку на локально значимую, не заглядывая в IP.
  • 4Pop — выходной узел снимает метку, дальше пакет идёт как обычный IP.
— ПРИМЕР
CLI-пример

Готовый конфиг для копирования — синтаксис Cisco IOS, адаптируйте под свою схему адресации.

Включение MPLS с LDP 
Router(config)# mpls label protocol ldp
Router(config)# interface GigabitEthernet0/0
Router(config-if)# mpls ip
Router# show mpls ldp neighbor
Router# show mpls forwarding-table

mpls ip включается на каждом транзитном интерфейсе внутри MPLS-домена — на клиентских портах (CE-facing) он не нужен.

03 — ГЛОССАРИЙ
Термины модуля

Короткий справочник — можно оставить открытым рядом с CLI.

LSP
Label Switched Path — путь через MPLS-домен, по которому коммутируется определённая метка/FEC.
LFIB
Label Forwarding Information Base — таблица пересылки по меткам, аналог таблицы маршрутизации.
Ingress / Egress PE
Входной и выходной провайдерский роутер MPLS-домена, где пакет получает и теряет метку.
P-роутер (core)
Транзитный роутер внутри MPLS-домена, который видит только метки, не сервисные детали клиента.
TTL в MPLS
У метки тоже есть поле TTL, убывающее на каждом хопе — нужно для traceroute и защиты от петель.
EXP / Traffic Class
Биты в MPLS-заголовке, несущие QoS-маркировку метки (аналог DSCP на уровне метки).
RSVP-TE
Альтернативный LDP протокол распределения меток, умеющий резервировать полосу и явно задавать путь.
Penultimate Hop
Предпоследний роутер на LSP — тот, что делает PHP перед egress PE.

MPLS L2VPN: эмуляция канального соединения поверх MPLS

VPWS и VPLS переносят Ethernet-кадры клиента через MPLS core прозрачно — для CE это выглядит как обычный провод или коммутатор, а не как сеть провайдера.

ФОРМАТтеория + схема + квиз
ВРЕМЯ~11 минут
Ethernet-кадр через pseudowire
ключевой узел на схемесоседний / промежуточный узел
  1. 1Ethernet-кадр от CE1, как есть
  2. 2PE1 заворачивает кадр в pseudowire (VC-метка + транспортная)
  3. 3MPLS core коммутирует по меткам, не разбирая Ethernet внутри
  4. 4PE2 снимает метки, кадр приходит на CE2 таким же, каким был

Для CE1 и CE2 это выглядит как один прямой канал — они не видят и не должны видеть, что внутри MPLS core.

01 — ТЕОРИЯ
Из чего состоит решение L2VPN

Шесть понятий — от VPWS до EVPN, который постепенно вытесняет VPLS.

Проще говоря: вместо IP VPN провайдер просто перекидывает клиенту Ethernet-кадры через свою MPLS-сеть — как будто это один длинный провод.

VPWS
Virtual Private Wire Service — точка-точка: имитирует один выделенный кабель между двумя CE, без коммутации между несколькими клиентами.
VPLS
Virtual Private LAN Service — точка-многоточка: PE ведут себя как виртуальный коммутатор, объединяя несколько CE в один общий L2-домен поверх MPLS.
Pseudowire
Логический канал через MPLS core, эмулирующий определённый L2-сервис (обычно Ethernet) между двумя PE.
VC Label
Virtual Circuit метка — внутренняя метка pseudowire, которая говорит PE, к какому именно сервису/клиенту относится кадр.
H-VPLS
Hierarchical VPLS — иерархическая версия с разделением на access- и core-уровень, чтобы не городить full-mesh pseudowire между всеми PE напрямую.
MAC learning в VPLS
Так как VPLS эмулирует коммутатор, PE учат MAC-адреса клиентов так же, как обычный L2-коммутатор — только через pseudowire вместо физических портов.
— ЧАСТЫЕ ЗАБЛУЖДЕНИЯ
Что обычно путают

Типичные неверные представления про эту тему — и как на самом деле.

КажетсяL2VPN и L3VPN — просто разные названия одной и той же услуги.
На делеL2VPN передаёт кадры Ethernet как есть (клиент сам маршрутизирует у себя), L3VPN — провайдер участвует в маршрутизации клиента через VRF.
КажетсяVPLS создаёт туннели между каждой парой PE вручную.
На делеVPLS автоматически строит full-mesh псевдопроводов между PE, эмулируя один большой коммутатор — вручную конфигурировать каждую пару не нужно.
02 — ПРОЦЕСС
Что происходит с Ethernet-кадром по дороге

Четыре шага — от CE1 до появления в исходном виде на CE2.

  • 1Приём — Ethernet-кадр от CE1 приходит на PE1 без изменений.
  • 2Инкапсуляция — PE1 добавляет VC-метку (сервис) и транспортную метку (путь до PE2).
  • 3Транзит — MPLS core коммутирует пакет по меткам, не заглядывая внутрь Ethernet.
  • 4Деинкапсуляция — PE2 снимает обе метки и отдаёт кадр на CE2 в исходном виде.
— ПРИМЕР
CLI-пример

Готовый конфиг для копирования — синтаксис Cisco IOS, адаптируйте под свою схему адресации.

Точка-точка VPWS через xconnect 
Router(config)# interface GigabitEthernet0/1
Router(config-if)# xconnect 10.0.0.2 100 encapsulation mpls
Router# show mpls l2transport vc

10.0.0.2 100 — это адрес удалённого PE и VC ID псевдопровода; на другом конце должна быть точно такая же пара.

03 — ГЛОССАРИЙ
Термины модуля

Короткий справочник — можно оставить открытым рядом с CLI.

CE
Customer Edge — граничное устройство клиента, не знающее, что внутри MPLS VPN, а не выделенный кабель.
Attachment Circuit
Физический или логический интерфейс на PE, через который CE подключается к pseudowire.
Multi-homing (VPLS)
Подключение CE к двум и более PE для резервирования — требует механизма выбора активного пути.
Split Horizon (VPLS)
Правило "не отправлять кадр обратно туда, откуда он пришёл по pseudowire" — защита от петель без STP между PE.
Targeted LDP
Сессия LDP, устанавливаемая не с прямым соседом, а с удалённым PE специально для сигнализации pseudowire.
QinQ
Двойное тегирование VLAN (802.1ad), часто используется на стыке с VPLS, чтобы пронести VLAN клиента внутри VLAN провайдера.
EVPN
Более новая технология, постепенно вытесняющая VPLS: использует BGP для MAC learning вместо data-plane флуда.
Full-mesh pseudowire
Топология, при которой каждый PE напрямую соединён pseudowire с каждым другим — быстро растёт по числу сессий с ростом числа PE.

VLAN: граница широковещательного домена

VLAN режет один физический L2-сегмент на несколько логически изолированных широковещательных доменов, ничего не меняя в кабелях — только в том, как коммутатор помечает и пересылает кадры.

01 — ТЕОРИЯ
Из чего состоит решение коммутатора

Шесть понятий — база, без которой не читается ничего дальше по курсу.

Проще говоря: VLAN режет один физический коммутатор на несколько виртуальных, чтобы широковещательный трафик одной группы не мешал другой.

Broadcast domain
Все устройства в одном broadcast-домене получают широковещательные кадры друг друга. VLAN — способ разбить один физический сегмент на несколько таких доменов.
Access / Trunk порты
Access-порт передаёт трафик одного VLAN без тегов. Trunk-порт переносит несколько VLAN одновременно, добавляя тег 802.1Q.
CAM-таблица
Таблица соответствия MAC-адрес → порт, которую коммутатор строит сам, слушая исходящие от хостов кадры (self-learning).
Unknown unicast flood
Если MAC назначения не найден в CAM-таблице, кадр отправляется на все порты этого VLAN, кроме входящего.
802.1Q тег
4-байтовый тег внутри Ethernet-кадра, который несёт номер VLAN между коммутаторами на trunk-линке.
Native VLAN
VLAN на trunk-порту, кадры которого передаются без тега. Несовпадение native VLAN на двух концах транка — частая причина странных проблем.
— ЧАСТЫЕ ЗАБЛУЖДЕНИЯ
Что обычно путают

Типичные неверные представления про эту тему — и как на самом деле.

КажетсяVLAN — это просто способ пометить трафик, физическая топология не важна.
На делеVLAN — это отдельный широковещательный домен; чтобы два VLAN обменивались трафиком, нужна маршрутизация (L3), одного тегирования недостаточно.
КажетсяTrunk-порт пропускает только тегированный трафик.
На делеTrunk обычно пропускает и нетегированный native VLAN трафик — частый источник путаницы и уязвимостей (VLAN hopping).
02 — ПРОЦЕСС
Что коммутатор делает с каждым кадром

Четыре шага — одинаковые для любого кадра, независимо от того, найден MAC или нет.

  • 1Приём — кадр приходит на access-порт, коммутатор запоминает VLAN этого порта.
  • 2Поиск — коммутатор ищет MAC-адрес назначения в CAM-таблице этого VLAN.
  • 3Найден → Forward — кадр отправляется только на порт, где ранее видели этот MAC.
  • 4Не найден → Flood — кадр рассылается на все порты VLAN, ответ учит CAM-таблицу.
— ПРИМЕР
CLI-пример

Готовый конфиг для копирования — синтаксис Cisco IOS, адаптируйте под свою схему адресации.

Access- и trunk-порты 
SW1(config)# vlan 10
SW1(config-vlan)# name USERS
SW1(config-vlan)# exit
SW1(config)# interface GigabitEthernet0/1
SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 10
SW1(config-if)# exit
SW1(config)# interface GigabitEthernet0/24
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk allowed vlan 10,20,30
SW1(config-if)# switchport trunk native vlan 999

native vlan лучше сознательно вынести на неиспользуемый VLAN (здесь 999) — это закрывает один из классических векторов VLAN hopping.

03 — ГЛОССАРИЙ
Термины модуля

Короткий справочник — можно оставить открытым рядом с CLI.

VLAN
Virtual LAN — логически изолированный широковещательный домен поверх общей физической инфраструктуры.
802.1Q
Стандарт тегирования кадров номером VLAN на trunk-линках.
Trunk
Линк между коммутаторами (или коммутатором и роутером), переносящий несколько VLAN одновременно.
CAM-таблица
Content Addressable Memory — таблица MAC → порт для быстрой пересылки кадров.
SVI
Switch Virtual Interface — виртуальный L3-интерфейс VLAN для маршрутизации между VLAN.
Native VLAN
VLAN на trunk-порту, кадры которого идут без 802.1Q тега.
Voice VLAN
Отдельный VLAN для IP-телефонов, обычно с приоритетной QoS-меткой.
Broadcast storm
Бесконечное размножение широковещательного трафика при физической петле без STP.
